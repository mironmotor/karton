# karton

Рабочие материалы по контенту Karton Pay (@nikitakonev → @Kartonpay_bot).

## Что внутри

| Путь | Что это |
| --- | --- |
| `index.html` | Страница проекта: в чём проблема отбора сценариев и как устроена система |
| `huk/index.html` | Разбор ленты + 30 готовых к съёмке хуков по шести направлениям |

## Суть

Ролики снимаются по одной механике, а просмотры гуляют от 249 до 231 000.
Сценарий проверяется уже после того, как за него заплачено съёмочным днём.

Система переставляет проверку вперёд: сначала снимаются только первые три
секунды каждого хука, замеряется удержание, и полноценно снимается лишь то,
что тест пережило.
